# Universal Dragon Voice Core

Private voice assistant foundation for Universal Dragon.

## Role

Voice processing layer connecting voice input, assistant logic, and safe actions.

## Architecture

```
Voice Input
 ↓
Voice Core
 ↓
NOVA / EVE
 ↓
Approval Layer
 ↓
Action Services
```

## Goals

- Natural voice interaction
- Multi-language support
- Future emotion and voice improvements
- Safe device control

## Safety

- Approval required for important actions
- No private credentials stored in repository
- Hardware actions must be controlled safely

## Status

Private development repository.
